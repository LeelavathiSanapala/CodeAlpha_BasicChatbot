# Basic Chatbot Using Python

## Project Description
This is a simple rule-based chatbot developed using Python. It interacts with users through text and provides responses to basic messages.

## Features
- Greets the user
- Responds to basic questions
- Answers thank-you messages
- Ends the conversation when the user types "bye"
- Handles unknown messages

## Technologies Used
- Python

## How to Run
1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

   python chatbot.py

## Sample Interaction
User: hello
Bot: Hello! How can I help you?

User: thank you
Bot: You're welcome!

User: bye
Bot: Goodbye! Have a nice day!
